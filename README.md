# 🏹 HuntersAllinOneForever

Welcome to **HuntersAllinOneForever**, a comprehensive user interface and resource suite custom-built for the unique mechanics of **WoW Forever**. This project unifies everything a Hunter needs to master their class—combining pet stat-scaling matrices, intelligent gear journals, smart cooldown tracking, and automated inventory safety triggers into a single, high-performance package.

### ✨ Core Features
* **🐾 Dynamic Pet Matrix:** Real-time loyalty trackers, feeding countdowns, and Focus-spending alerts.
* **⚔️ Integrated Gear Journal:** Specialization-specific itemization guidelines for Beast Mastery, Marksmanship, and Survival.
* **🏹 Visual Rotation Dashboard:** Shot-timer optimization, multi-hawk meta trackers, and dynamic ammo counting.
* **⚙️ Expert Macro Suite:** Single-button pet management and seamless auto-shot safety triggers.
